# Optionality

Optionality is the value of retaining future choices.

When uncertainty is high, irreversible decisions demand more evidence than reversible ones.

Useful questions include:

- Does this choice close doors?
- Can I test before committing?
- What information might arrive later?
- Can I make the decision smaller?
- What is the cost of waiting?
- What is the value of remaining able to change direction?

Optionality is not indecision. It is deliberate preservation of maneuver.
