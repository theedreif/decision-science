# Probability

Uncertainty is not the absence of information. It is a condition for making better estimates.

Probability thinking replaces **Will this happen?** with questions such as:

- How likely is it?
- What is the base rate?
- What evidence should change the estimate?
- How confident should I be?
- What is the cost of being wrong?
- What happens across repeated trials?

A probability is not a promise. It is a way to reason before the outcome is known.
