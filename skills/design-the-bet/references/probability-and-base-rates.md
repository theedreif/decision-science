# Probability and Base Rates

## Think in likelihoods, not certainties

A decision can be rational without certainty. State uncertainty rather than disguising it.

## Base rates

Before focusing on the uniqueness of the current case, ask whether relevant historical or population-level evidence exists.

Use base rates carefully:
- confirm the comparison population is relevant;
- identify differences between the reference class and current case;
- prefer current and authoritative evidence where stakes are high;
- do not invent a base rate when none is available.

## Improving the odds

Possible levers include:
- acquiring information;
- practicing;
- selecting better timing;
- reducing complexity;
- improving incentives;
- changing position size;
- running a small experiment;
- seeking expertise;
- repeating favorable low-downside trials.

## Calibration

Confidence should track evidence.

If a numeric probability cannot be supported, say so. Use scenarios or qualitative uncertainty instead of false precision.
